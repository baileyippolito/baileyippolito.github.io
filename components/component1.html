Buttons

Usage

Buttons are mainly used to interact with cards. They are black with white text, and switch to gray with black text upon hover.

Accessibility Considerations

Buttons are designed to be high contrast with a black background and white text as default. Upon hover, background should change to Nimbus Gray with black text. Both color combinations are in accordance with WCAG contrast guidelines. All buttons include visual focus indicators for keyboard navigation and screen readers.

Button
Code Example

<!-- Button HTML -->
<a href="#" class="btn-primary px-5 montserrat-body">Button</a>

<!-- Button CSS -->
.btn-primary {
  background-color: black;
  color: white;
  box-shadow: none;
  border-radius: 10px;
  padding: 12px;
}

.btn-primary:hover {
  background-color: #C5D2DF;
  color: black;
  box-shadow: none;
  border-radius: 10px;
  padding: 12px;
}

.btn-primary:active {
  background-color: #C5D2DF;
  color: black;
  box-shadow: inset 0 2px 4px rgba(0, 0, 0, 0.2);
  border-radius: 10px;
  padding: 12px;
}

a {
  text-decoration: none !important;
}
