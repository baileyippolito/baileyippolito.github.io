Cards

Usage

Cards are used to preview portfolio projects. They contain the project title, a descriptive subtitle, and a concise, high-level explanation on the projects impact. Each card is labeled with tags to clearly communicate the skills utilized during the project.

Accessibility Considerations

All card images must utilize alt text in order to be compatible with screen reader capabilities. Text and background colors are designed to be high contrast consistent with WCAG requirements.
