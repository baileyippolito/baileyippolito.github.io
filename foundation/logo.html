Logo Variations

Color

The color logo is the primary logo and should be used against light backgrounds.

Grayscale

The grayscale logo should be used when printing in color is not an option.

Color Inversed

The color inversed logo is an alternative to the main logo and can be used when more contrast is needed

B&W Inversed

The black and white inversed logo is an alternatice to the main grayscale logo and can be used when printing in color is not an option and more contrast is needed.

Favicon

The favicon logo should be used as a favicon in the browser tab. The name should not be included in the Favicon logo.
